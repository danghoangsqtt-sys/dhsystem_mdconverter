# T8.5 — Portable runtime and offline packaging

## Objective

Build installer không phụ thuộc Python/user caches và packaged conversion không phát sinh network request.

## Paths

```text
frontend/electron/main.ts
frontend/package.json
backend/src/services/docling_service.py
scripts/prepare-offline-bundle.ps1
.gitignore
README.md
```

## Implementation Notes

- Ưu tiên `resources/python_runtime/python.exe`; không chấp nhận venv trong packaged mode.
- Runtime validation chạy Python với `-s`.
- Tải `layout`, `tableformer`, `easyocr` vào `offline_models`.
- Packaged environment bắt buộc offline flags và explicit artifacts path.

## Verification

- Preflight phát hiện EasyOCR/model/runtime thiếu.
- `sys.base_prefix` nằm trong resources runtime.
- Manual clean-machine installer test là release gate cuối.
