# T8.1 — API security and resource limits

## Objective

Đóng path traversal/CORS/CSRF-like local API exposure, validate upload và đảm bảo conversion không chạy không giới hạn.

## Paths

```text
backend/src/config.py
backend/src/main.py
backend/src/services/job_service.py
frontend/src/services/api.ts
frontend/electron/main.ts
frontend/electron/preload.ts
frontend/src/electron.d.ts
backend/tests/test_api_security.py
```

## Implementation Notes

- Session token dùng `secrets.token_urlsafe` và compare constant-time.
- Bootstrap endpoint kiểm tra Origin ở server, không chỉ dựa vào CORS middleware.
- UUID được parse trước khi dựng path.
- Upload lưu theo chunk trên worker thread, fail và cleanup khi quá giới hạn.
- Conversion concurrency mặc định là 1.

## Verification

- Traversal request không trả nội dung file.
- Missing/wrong token trả 401.
- Untrusted bootstrap origin trả 403.
- Oversize/unsupported upload trả 413/415 và không để file tạm.
