# T13.3 — Tini OCR Image Pipeline

## Objective

Hoàn thiện vertical slice local: ảnh điện thoại → tiền xử lý → OCR → review → TXT/Markdown/DOCX.

## Work

- Viết image validation bằng magic bytes, giới hạn byte/dimension/pixel và safe decode.
- Thêm EXIF orientation, rotate/crop, perspective correction, deskew, contrast/illumination/shadow presets; giữ nguyên file gốc.
- Benchmark RapidOCR/ONNX candidate với EasyOCR baseline trên fixture khóa; chỉ chọn default sau quality/license/bundle gate.
- Thiết kế OCR result contract page/block/line/box/confidence và API job/cancel/review revision.
- Thêm UI nhập một/nhiều ảnh/thư mục, reorder, progress theo trang, overlay, confidence warning và text editor.
- Xuất TXT, Markdown, DOCX editable và DOCX image-faithful; cleanup output tạm đầy đủ.
- Ghi engine/model/preprocessing recipe để có thể tái hiện lỗi.

## Acceptance

- JPG/PNG hợp lệ đi hết pipeline offline; ảnh hỏng/bomb bị từ chối an toàn.
- Batch lỗi một ảnh vẫn báo kết quả rõ cho các ảnh còn lại; cancel không lưu success giả.
- Candidate mặc định đạt quality gate trong SPEC hoặc fallback có ghi nhận rõ.
- Bốn định dạng output đủ trang, đúng thứ tự; editable DOCX khớp text đã review.
- Không có model download ngầm và ảnh gốc không bị thay đổi.
