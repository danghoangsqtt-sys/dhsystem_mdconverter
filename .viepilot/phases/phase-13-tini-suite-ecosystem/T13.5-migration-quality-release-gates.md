# T13.5 — Migration, Quality and Release Gates

## Objective

Chứng minh Tini Suite đủ an toàn để nâng từ v1.5.0 và chỉ sau đó hoàn tất metadata v1.6.0.

## Work

- Chạy migration install/userData trên bản sao dữ liệu v1.5.0 và kiểm tra idempotency.
- Khóa OCR benchmark fixture, baseline, CER report và failure buckets.
- Chạy toàn bộ backend/frontend/Electron regression và test ma trận concurrent Core.
- Thực hiện fresh install, upgrade, uninstall và offline smoke trên máy Windows sạch.
- Kiểm tra accessibility/keyboard ở luồng import, review và export cơ bản.
- Cập nhật hướng dẫn hai product, mode DOCX, yêu cầu máy, riêng tư và USB distribution.
- Sau khi mọi gate đạt: bump package/UI/installer lên 1.6.0 và chuyển changelog từ Planned sang Released.

## Acceptance

- Upgrade v1.5.0 không mất history/cấu hình và chạy lại migration không tạo bản sao.
- OCR benchmark, security, bundle-size, clean-machine offline và regression gates đều đạt.
- Cả hai product có keyboard flow cơ bản và trạng thái lỗi có thể hiểu được.
- Mọi nơi hiển thị version đồng bộ 1.6.0 chỉ sau gate cuối.
- Setup candidate sẵn sàng copy qua USB; không có GitHub Release.
