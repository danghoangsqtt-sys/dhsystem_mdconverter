# T13.4 — Dual-entry Offline Installer

## Objective

Tạo một NSIS installer offline có hai shortcut product và đúng một bản runtime/model.

## Work

- Cấu hình shared executable host và custom shortcut `Mark Tini`, `Tini OCR` với cờ/icon tương ứng.
- Bảo đảm uninstall duy nhất và shortcut cũ v1.5.0 được nâng cấp/thay thế sạch.
- Bundle RapidOCR artifact đã khóa hash nếu T13.3 chọn engine này.
- Thêm kiểm kê file/hash để build fail khi Python runtime hoặc model bị duplicate.
- Tạo báo cáo size delta so với installer v1.5.0 và nguồn/license của model.
- Smoke packaged layout với network disabled, đường dẫn Unicode và lưu output ra USB.

## Acceptance

- Một installer tạo hai shortcut đúng product và một uninstall entry.
- File audit chứng minh không duplicate runtime/model artifact.
- Máy sạch không có Python/Node/Ollama và không Internet vẫn chạy cả hai product.
- Installer delta không vượt gate SPEC hoặc có phê duyệt/giải trình riêng.
- Không tạo hoặc tải GitHub Release.
