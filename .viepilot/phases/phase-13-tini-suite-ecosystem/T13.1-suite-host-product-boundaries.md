# T13.1 — Shared Host and Product Boundaries

## Objective

Tạo hai product shell độc lập trong cùng frontend/Electron host mà không làm thay đổi hành vi hiện tại của Mark Tini.

## Work

- Thêm parser allowlist cho `--product=mark-tini|tini-ocr`; giá trị lạ phải fail closed về Mark Tini hoặc báo lỗi có chủ đích.
- Tách product root Mark Tini khỏi bootstrap chung bằng migration cơ học, tránh refactor nghiệp vụ cùng lúc.
- Tạo Tini OCR shell gồm onboarding, import empty state, page list/review/export placeholder.
- Tách shared UI primitives, API contracts và product-scoped settings/history keys.
- Thiết lập tên cửa sổ, icon và AppUserModelID theo product.
- Bổ sung E2E chứng minh hai cửa sổ mở đồng thời và Mark Tini không hồi quy.

## Paths

## File-Level Plan

- `frontend/electron/main.ts`: parse product ID bằng allowlist, chọn metadata cửa sổ/AppUserModelID và truyền product bootstrap qua preload argument; không thay đổi backend lifecycle trong task này.
- `frontend/electron/preload.ts`: expose product ID dạng read-only cùng purpose-specific bridge hiện có.
- `frontend/src/electron.d.ts`: khai báo contract product ID cho renderer.
- `frontend/src/main.tsx`: render `ProductRoot` thay vì gắn trực tiếp Mark Tini `App`.
- `frontend/src/products/mark-tini/MarkTiniApp.tsx`: adapter product root bảo toàn nguyên trạng `App.tsx` để giới hạn regression surface.
- `frontend/src/products/tini-ocr/TiniOcrApp.tsx`: product shell riêng gồm onboarding, import empty state, workflow cards và trạng thái “pipeline sẽ được kích hoạt ở T13.3”.
- `frontend/src/products/tini-ocr/tini-ocr.css`: responsive layout và focus-visible states, không phụ thuộc CSS Mark Tini.
- `frontend/src/shared/product.ts`: product ID/metadata/normalization dùng chung; browser dev mặc định an toàn về Mark Tini.
- `frontend/e2e/app.spec.ts`: khởi chạy explicit Mark Tini và thêm smoke test Tini OCR riêng, xác minh title/nội dung/không lộ control Mark Tini.

## Best-Practice Checklist

- Product ID là union type và mọi input ngoài allowlist fallback về `mark-tini`.
- Renderer không đọc raw `process.argv`; preload chỉ expose giá trị đã chuẩn hóa.
- Không refactor logic nghiệp vụ trong `App.tsx` cùng task tách shell.
- Giữ `contextIsolation`, `sandbox` và bridge tối thiểu.
- UI mới dùng semantic HTML, keyboard focus, responsive layout và không hứa OCR đã hoạt động trước T13.3.

## Acceptance

- `--product=mark-tini` hiển thị toàn bộ UI và chức năng Mark Tini hiện tại.
- `--product=tini-ocr` hiển thị UI riêng, không lộ control không liên quan của Mark Tini.
- Hai product mở đồng thời, có title/icon/settings namespace riêng.
- Frontend lint/build, React Doctor changed scope và Electron regression E2E đạt.
